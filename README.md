# Купи и выиграй с Атемарской

Серверная часть промо-акции «Купи и выиграй с Атемарской» (ТМ «Атемарская Ферма»,
организатор — ООО «ЧНГ», заказчик — АО «Птицефабрика «Атемарская»).

* Лендинг — https://af-promo.ru
* Личный кабинет участника — https://af.cheqly.ru
* Поддержка участников — af@cheqly.ru

Проект собран по образцу акции «Омский бекон»: тот же стек, та же структура и тот
же набор подсистем (приём и проверка чеков через ФНС, модерация, розыгрыши,
победители, договоры OkiDoki, письма, электронные призы, панель персонала,
аналитика, выплаты через Точку). Отличий два: **моментальные призы** («лоток
яиц») и **лендинг, собранный из секций** по образцу PromoTemplate.

## Сроки и механика (бриф)

| Что | Когда / сколько |
| --- | --- |
| Период покупки и регистрации чеков | 01.10.2026 — 10.01.2027 |
| Недельных периодов | 14 (первый — 01.10 – 11.10, дальше пн–вс) |
| Еженедельные розыгрыши | каждую среду, 14.10.2026 — 13.01.2027 |
| Главный розыгрыш | 13.01.2027 |
| Вручение призов | 01.10.2026 — 31.01.2027 |
| Еженедельные призы | Ozon 500 ₽ × 50, Ozon 1000 ₽ × 25, аэрогриль × 5 — на каждую неделю |
| Моментальные призы | Ozon 500 ₽ × 50/нед., аэрогриль × 30/нед. |
| Главный приз | холодильник × 5 |
| Где покупать | любые магазины РФ, без ограничений по сети, формату и региону |
| Минимальная сумма чека | нет |
| Лимит чеков на участника | нет |

**Сколько призов может выиграть один участник** (см. `promotion/services/prize_limits.py`):

* не более одного моментального приза за всю акцию;
* не более одного приза в еженедельных и ежемесячных розыгрышах вместе взятых —
  выиграл еженедельный, значит второй еженедельный и ежемесячный ему уже не
  достанутся;
* Главный розыгрыш по умолчанию считается отдельно (переключается одной
  константой `MAIN_DRAW_SHARES_REGULAR_LIMIT`).

## Моментальные призы — «лоток яиц»

Механика целиком описана в [docs/instant-prizes.md](docs/instant-prizes.md).
Коротко:

1. Чек приняли → участнику начислилась попытка (`InstantAttempt`).
2. При следующем заходе в кабинет открывается модалка с лотком из десяти яиц.
3. Участник открывает одно яйцо → внутри приз или пусто. Остались попытки —
   кнопка «Попробовать ещё раз».
4. Выигрыш определяется **призовыми моментами** (`InstantMoment`) — заранее
   сгенерированным расписанием, равномерно размазанным по всем дням акции.
   Поэтому каждый день уходит примерно одинаковое количество призов, а фонд не
   заканчивается раньше срока и не остаётся неразыгранным.

## Структура

    config/           проект Django: settings, celery, urls, sitemaps
    main/             публичная часть: лендинг из секций, SEO, FAQ, реквизиты
    promotion/        участники, чеки, призы, розыгрыши, моментальные призы,
                      письма, договоры OkiDoki, выплаты через Точку (Cyclops)
    staff_panel/      рабочее место менеджера: чеки, призы, участники,
                      победители, моментальные призы, аналитика
    templates/        base.html, pages/, partials/sections/, seo/
    static/           css/landing (токены и оформление), css|js/participants,
                      favicons, шрифты
    docs/             документация подсистем

Лендинг собирается из секций `templates/partials/sections/`: страница — это набор
`{% include %}`, а тексты секций лежат в БД (`main.ContentBlock`). Лишняя секция
выключается галочкой в админке, а не удаляется из шаблона. Оформление вынесено в
CSS-токены `static/css/landing/tokens.css` — когда приедет брендбук, правится
один файл.

## Локальный запуск

    python -m venv venv && venv/Scripts/activate      # Windows
    pip install -r requirements.txt
    cp .env.example .env                              # DEBUG=True → SQLite + моки ФНС
    python manage.py migrate
    python manage.py seed_promo_calendar              # сроки, призы, призовые моменты
    python manage.py createsuperuser
    python manage.py runserver

`seed_promo_calendar` приводит БД к состоянию «можно работать»: заводит календарь
акции, все призы по брифу и расписание призовых моментов. Команда идемпотентна.

Тестовые данные для разработки (участники, чеки, победители):

    python manage.py seed_dev_data

## Боевой запуск

    docker compose up -d --build
    docker compose exec backend python manage.py migrate
    docker compose exec backend python manage.py seed_promo_calendar
    docker compose exec backend python manage.py createsuperuser

Перед стартом акции обязательно:

1. Заполнить реквизиты организатора и документы в админке (`Информация о компании`).
2. Проверить призовой фонд на вкладке «Моментальные» в панели: расписание должно
   быть сгенерировано, столбики по дням — примерно одинаковой высоты.
3. Включить боевой режим SEO (`Информация о компании` → «Боевой режим SEO»).
4. Сменить пароль учётной записи менеджера чеков `manager@cheqly.ru`
   (заводится миграцией `promotion.0002_seed_texts` с временным паролем).

## Команды

| Команда | Что делает |
| --- | --- |
| `seed_promo_calendar` | Календарь акции, призовой фонд и призовые моменты по брифу |
| `generate_instant_moments` | Пересобрать расписание призовых моментов (`--week`, `--dry-run`) |
| `process_raffle` / `process_raffle_main` | Ручной запуск розыгрышей |
| `seed_receipt_messages` | Дефолтные тексты сообщений о статусе чека |
| `seed_dev_data` | Тестовые данные для разработки |
| `sync_oki_documents`, `sync_sbp_banks` | Синхронизации с внешними системами |

Раз в сутки Celery присылает в Telegram сводку по моментальным призам: сколько
их разыграно, сколько осталось и не отстаёт ли выдача от графика.

## Переменные окружения

Полный список — в `.env.example`. Обязательные для боя: `SECRET_KEY`,
`ALLOWED_HOSTS`, `POSTGRES_*`, `OKI_DOKI_API_KEY`, `OPENROUTER_API_KEY`
(проверка чеков нейросетью), `FORWARD_SIGNAL_URL` (уведомления в Telegram).

## Тесты

    python manage.py test promotion staff_panel main

Механику моментальных призов покрывает `promotion/tests/test_instant_prizes.py`:
начисление попыток, ловля призовых моментов, равномерность расписания и лимит
«один моментальный приз на участника».
